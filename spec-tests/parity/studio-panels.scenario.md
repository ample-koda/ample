# Effect studio panel parity scenario

1. Open an effect's advanced controls from both its canvas node and its properties card.
2. Verify every template parameter appears with its declared type, unit and range; verify generic panels exist for non-effect blocks.
3. Change a parameter with a gesture, then undo once and verify the original value returns.
4. Toggle bypass, open A/B, close with Escape and verify keyboard focus returns to the entry button.
5. Open a read-only history state and verify controls display without committing edits.
