# Studio control gallery parity scenario

1. Open the app and change the theme to light; verify the document attribute, stored preference and token-driven background, then restore studio dark.
2. Open the app with `?gallery=1` and verify the knob, fader, LED, selector, readout, meter, curve, scrub bar and XY controls.
3. Double-click inside the curve to add a point, move it with the keyboard, and delete it; endpoint anchors remain fixed.
4. Shift-drag the scrub bar to select a loop, then drag normally to seek without changing the loop.
5. Drag the knob right/up and left/down; Shift-drag is finer and the cursor is hidden. Escape cancels, release commits once, and the keyboard, wheel, reset and typed-value paths work.
6. Check slider ARIA values and reduced motion; scrub a waveform and edit curve points with keyboard and cancel behavior.
