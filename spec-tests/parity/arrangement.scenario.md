# Arrangement parity scenario

1. Move a clip by dragging its body and resize it from either edge; each gesture commits as one undo step. If a configured bar scope would overrun the shortened clip, choose to trim it, keep it, or cancel the resize.
2. Double-click a clip or use its context menu to edit exact start and length. The context menu also opens the block in source.
3. Expect the versioned document edit to update source placements and cache keys, show unsaved state, and preserve bar positions after reload.
