# Keyboard shortcuts

On a Mac, use Cmd where this page says Ctrl. A key is only active when you are not typing in a text field.

## Everywhere

| Keys | What it does |
|---|---|
| Space | Play, or stop when something plays |
| Ctrl+B | Build |
| Ctrl+S | Save |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |
| Esc | Close a menu, a card or the projects view |

Ctrl+Enter is not Build: in the Source view it **applies** the text you typed.

## The node editor

| Keys | What it does |
|---|---|
| Wheel | Zoom around the pointer |
| Drag the background | Pan |
| F | Fit the whole song in view |
| Ctrl+A | Select all blocks |
| Click, Ctrl+click or Shift+click | Select, add to the selection |
| Shift+drag a rectangle | Select the blocks inside it |
| Arrow keys | Move the selected blocks a little (Shift: a lot) |
| Delete | Remove the selected blocks, or the selected cable |
| Ctrl+G | Group the selected blocks (Ctrl+Shift+G: ungroup) |
| Alt+Up | Go up out of a group |
| Enter on a block | Open its source (or enter a group) |
| Double-click a block | Open its source |

## The Source view

| Keys | What it does |
|---|---|
| Ctrl+Enter | Apply the text to the song |
| Ctrl+P | Open the file switcher: type a few letters of a file name |
| Ctrl+click on a name | Go to that block, or open that file |

## The piano roll

| Keys | What it does |
|---|---|
| Space | Play the notes |
| Ctrl+A | Select all notes |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut, paste |
| Ctrl+D | Copy the selected notes next to themselves |
| Delete | Remove the selected notes |
| Ctrl+wheel | Zoom the time |
| Alt+wheel | Make the rows taller or shorter |
| `,` and `.` | Select the previous or the next note |
| Z and X (step input) | One octave down or up |

> **Tip** Hover over a button: most of them say in their tooltip what it does and which key goes with it.
