---
| Word | Meaning |
|---|---|
| accent | a note played stronger than the rest |
| arpeggio | the notes of a chord played one after the other |
| attack | how fast a sound reaches full volume |
| backbeat | the strong beats 2 and 4 in a 4/4 bar |
| bar (measure) | a group of beats, often four |
| beat | the steady pulse of a song |
| bpm | beats per minute, the tempo |
| chord | several notes played together |
| clipping | distortion when a sound is too loud |
| compressor | a tool that turns down the loud parts |
| crescendo | gradually louder |
| decay | how a sound fades after its start |
| delay | an echo |
| diminuendo | gradually softer |
| dynamics | changes in loudness |
| EQ | a tool that boosts or cuts frequency bands |
| envelope | the shape of a sound's loudness over time |
| fifth | the interval of seven semitones |
| filter | removes part of the sound's frequencies |
| frequency | how fast something vibrates, in Hz |
| harmony | notes sounding together |
| interval | the distance between two notes |
| key | the home note and scale of a song |
| kick | the low drum thump |
| LFO | a slow wave used to move a setting |
| limiter | a compressor that stops peaks |
| major | the bright scale or chord |
| melody | the line you sing |
| minor | the dark scale or chord |
| mode | a scale started from another note |
| octave | twelve semitones, the same note higher |
| pad | a long, soft, sustained sound |
| pan | placing a sound left or right |
| pentatonic | a five-note scale |
| pitch | how high or low a note is |
| reverb | the sound of a room |
| rest | a silence with a length |
| resolution | the arrival of a tense chord at a calm one |
| rhythm | the pattern of long and short sounds |
| root | the note a chord is named after |
| sample | a recording used as a sound |
| scale | a set of notes that belong together |
| semitone | the smallest step on a keyboard |
| snare | the sharp drum on the backbeat |
| sustain | the level a sound holds while a key is held |
| swing | uneven eighth notes with a bouncy feel |
| syncopation | accents between the beats |
| tempo | the speed of the beat |
| timbre | the colour of a sound |
| triad | a three-note chord |
| triplet | three notes in the space of two |
| velocity | how hard a note is played |
| voicing | which notes of a chord, and in what order |
